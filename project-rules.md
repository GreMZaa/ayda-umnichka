# 🏛️ Project Rules: Образовательная платформа «АйДаУмничка»

## 1. Контекст проекта и миссия
Ты — Senior Full-Stack Engineer и Архитектор платформы. Проект — интерактивная онлайн-платформа детского развивающего и учебного центра «АйДаУмничка» в г. Тольятти.
Система предназначена для проведения индивидуальных интерактивных онлайн-уроков 1-на-1 (логопедия, развитие речи, подготовка к школе, ментальная арифметика и др.), совместной работы на интерактивной онлайн-доске, постоянного сопровождения в мессенджере с голосовыми сообщениями, контроля баланса оплаченных занятий и прозрачного взаимодействия между учеником/родителем, педагогом и администрацией центра.

## 2. Технический стек и инфраструктура
* **Frontend:** Next.js (React 19 / App Router), TypeScript, TailwindCSS, shadcn/ui, Lucide React.
* **Хостинг и деплой:** Vercel (Hobby Tier, Edge & Node.js Serverless API routes).
* **База данных и Realtime:** Supabase:
  * PostgreSQL 16 со строгой защитой Row Level Security (RLS).
  * Supabase Auth: открытая регистрация пользователей, JWT-аутентификация.
  * Supabase Realtime (WebSockets): каналы Broadcast & Presence для WebRTC-сигналинга (обмен SDP Offer/Answer, ICE), синхронизации холста доски и чатов.
  * Supabase Storage: бакеты `avatars`, `homework`, `chat-attachments`, `voice-messages`.
* **Медиа и Видеосвязь:** Нативный WebRTC API браузера (`RTCPeerConnection`, `getUserMedia`, `getDisplayMedia`).
* **Устойчивость к «белым спискам» (РФ):** Прямое P2P-соединение (Peer-to-Peer) между браузерами внутри российских сетей без использования зарубежных коммерческих медиа-серверов (Zoom, Agora, Google Meet). STUN-серверы: общедоступные российские узлы (например, `stun.sipnet.ru`).
* **Интерактивная доска:** Легковесный масштабируемый векторный холст (HTML5 Canvas / SVG) с мгновенной трансляцией штрихов и фигур через Realtime Broadcast.

## 3. Критические правила безопасности и доступа
1. **Валидация JWT и ролевая модель:**
   * Все защищенные серверные эндпоинты валидируют сессию через Supabase Auth.
   * Роли пользователей: `student` (ученик/родитель), `teacher` (преподаватель), `admin` (руководство центра).
   * Ученик имеет доступ строго к своим диалогам, своим ДЗ, своему балансу и назначенным урокам.
   * Администратор управляет начислением уроков, привязкой связок «учитель — ученик» и ролями.
2. **Безопасность хранения и передачи файлов:**
   * Валидация MIME-типов и ограничение размера файлов (изображения до 10 МБ, аудио/документы до 50 МБ).
   * Защита хранилища Supabase Storage через политики доступа (пользователи могут скачивать только материалы своих уроков и диалогов).
3. **Безопасность WebRTC комнат:**
   * Вход в комнату урока возможен только по действительному `room_token` с проверкой прикрепления текущего пользователя к сессии.
   * Урок завершается учителем или администратором с автоматической фиксацией времени и списанием 1 занятия с баланса при длительности $>15$ минут.
4. **Защита от XSS и инъекций:**
   * Экранирование и санитизация текста сообщений и описаний заданий.
   * Строгая валидация входящих схем данных через Zod / TypeScript interfaces.

## 4. UI/UX и визуальные стандарты
* **Фирменная палитра центра «АйДаУмничка»:**
  * Основной цвет доверия и фокуса: мягкий индиго/лазурный `#4F46E5` (Primary).
  * Теплый солнечный акцент детского центра: `#F59E0B` (Accent / Warning / Награды).
  * Светлый чистый фон интерфейса: `#F8FAFC` (Slate-50) и карточки `#FFFFFF`.
  * Четкий контрастный текст: `#0F172A` (Slate-900).
* **Эргономика видеоурока (Yandex Telemost / Zoom style):**
  * Плавающая полупрозрачная панель управления звонком внизу экрана (Микрофон, Камера, Экран, Доска, Чат, Завершить).
  * Режим переключения «Видео ↔ Доска». В режиме доски видео собеседника аккуратно помещается в плавающее окно Picture-in-Picture (PiP).
* **Мобильная и планшетная адаптивность:**
  * Удобное управление пальцем на планшетах (iPad / Android-планшеты) для детей.
  * Крупные кнопки инструментов рисования на интерактивной доске (карандаш, маркер, ластик, фигуры).
* **Образовательный мессенджер (стиль Telegram / VK):**
  * Запись и отправка голосовых сообщений в 1 клик с отображением аудиоволны.
  * Уведомления об уроках и карточка быстрого перехода в активный звонок.
