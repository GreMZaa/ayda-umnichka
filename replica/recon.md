# Реверс-инжиниринг и анализ: Skillspace -> Платформа «АйДаУмничка»

## 1. Контекст и цели проекта

- **Продукт:** «АйДаУмничка» — специализированная онлайн-платформа для репетиторского центра.
- **Референс:** [Skillspace.ru](https://skillspace.ru) (LMS, кабинет преподавателя, ученика, организация онлайн-занятий).
- **Ключевое отличие и специфика:** 
  - Skillspace ориентирован в основном на курсы и инфобизнес.
  - «АйДаУмничка» строится вокруг **живых индивидуальных и групповых занятий (репетиторство)** с фокусом на треугольник взаимодействия: **Преподаватель — Ученик — Родитель**.
- **Стратегия запуска (MVP):**
  1. Встроенные видеоуроки прямо в браузере (без необходимости ставить Zoom/Skype).
  2. Три типа личных кабинетов (+ админ-панель центра):
     - **Преподаватель:** календарь уроков, карточки учеников, запуск видеокомнаты, заметки по уроку.
     - **Ученик:** список предстоящих занятий, кнопка «Войти на урок», доступ к видеокомнате.
     - **Родитель:** контроль расписания ребенка, посещаемость, комментарии репетитора, баланс уроков.
     - **Администратор центра:** управление репетиторами, учениками, распределение пар «учитель-ученик», общее расписание.
  3. Модульная архитектура для легкого добавления: ДЗ, интерактивной доски, автоплатежей и курсов.

## 3. Пользовательские сценарии (User Flows)

### F01. Проведение онлайн-урока (Преподаватель и Ученик)
1. Преподаватель открывает `/teacher/dashboard` -> видит урок в расписании.
2. За 10 минут до начала становится активна кнопка **«Начать урок»**.
3. Учитель входит в комнату `/room/:id` (камера, микрофон, демонстрация экрана).
4. Ученик видит в `/student/dashboard` статус «Учитель в классе» и нажимает большую кнопку **«Войти на урок»**.
5. Проходит занятие. По окончании учитель нажимает «Завершить урок» и оставляет краткий комментарий (что прошли, успехи).
6. Урок помечается как проведенный, родителю отправляется уведомление/отметка в кабинете.

### F02. Контроль родителем
1. Родитель заходит в кабинет `/parent/dashboard`.
2. Видит статус: «Маша — Урок математики сегодня в 16:00 (Преподаватель: Анна Сергеевна)».
3. После урока видит статус «Проведен» и комментарий преподавателя.

### F03. Назначение уроков (Администратор / Преподаватель)
1. Создание пары: Ученик + Преподаватель + Предмет.
2. Установка расписания (например, вторник и четверг в 16:00).
3. Автоматическая генерация слотов уроков с персональными ссылками на видеокомнату.

## 4. Архитектурный стек для быстрого и надежного старта

- **Frontend / Full-stack:** Next.js 14+ (App Router), React, Tailwind CSS, Lucide Icons (современный, быстрый интерфейс в духе Skillspace).
- **Backend / Database:** Node.js / Next.js Server Actions + PostgreSQL (через Prisma ORM) — полная изоляция данных, строгие связи между родителями, детьми и учителями.
- **Видеосвязь (Video Engine):** 
  - Интеграция с защищенным WebRTC движком (например, Jitsi Meet iframe API с кастомной темой или LiveKit Cloud / 100ms / Daily) — не требует от учеников и учителей скачивать сторонние программы, работает на смартфонах, планшетах и компьютерах в любом браузере.
- **Аутентификация:** NextAuth.js / Supabase Auth с ролевым доступом (`TEACHER`, `STUDENT`, `PARENT`, `ADMIN`).
