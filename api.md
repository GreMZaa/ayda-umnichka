# 📡 Документация API: Образовательная платформа «АйДаУмничка»

Базовый URL: `https://app.aidaumnichka.ru/api` (Next.js Serverless Edge & Node.js API Routes на Vercel)  
Инфраструктура: Supabase (PostgreSQL 16, Supabase Auth, Realtime Signaling & WebSockets, Storage).

---

## 🔐 Аутентификация и Заголовки
Все защищенные эндпоинты требуют передачи JWT-токена сессии Supabase Auth:
* **Заголовок:** `Authorization: Bearer <supabase_access_token>`.
* **Проверка:** Валидация подписи JWT через `@supabase/supabase-js` / Supabase Auth Middleware с извлечением `user_id` и проверкой роли в таблице `public.profiles`.

Роли доступа:
* `student` — ученик или родитель (доступ к своим урокам, чату с педагогом, ДЗ и балансу).
* `teacher` — преподаватель (создание on-demand уроков, ведение заметок, выдача и проверка ДЗ).
* `admin` — руководство детского центра «АйДаУмничка» (управление пользователями, связками педагог-ученик, балансом занятий и финансовой аналитикой).

## 1. Профиль и Пользователи

### `GET /api/profile`
* **Доступ:** `student`, `teacher`, `admin`.
* **Назначение:** Получение данных профиля текущего авторизованного пользователя.
* **Ответ:**
```json
{
  "id": "a8f1b2c3-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
  "email": "parent@example.com",
  "role": "student",
  "full_name": "Артём Иванов (мама: Ольга)",
  "phone": "+7 (927) 000-00-00",
  "avatar_url": "https://.../avatars/artem.png",
  "balance_lessons": 8,
  "created_at": "2026-10-24T10:00:00Z"
}
```

### `PUT /api/profile`
* **Доступ:** Авторизованный пользователь.
* **Назначение:** Обновление контактных данных (телефон, аватар, имя).

## 2. On-Demand Уроки и WebRTC Комнаты

### `POST /api/lessons/create`
* **Доступ:** `teacher`, `admin`.
* **Назначение:** Мгновенный запуск on-demand урока преподавателем, генерация комнаты и отправка пуш-приглашения ученику в чат.
* **Тело запроса:**
```json
{
  "student_id": "a8f1b2c3-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
  "topic": "Развитие речи: шипящие звуки Ш и Ж"
}
```
* **Ответ:**
```json
{
  "lesson_id": "99b00e33-72ce-4e12-8822-6b9dfa34e012",
  "room_token": "room-sh-zh-4821",
  "join_url": "https://app.aidaumnichka.ru/room/room-sh-zh-4821",
  "status": "pending"
}
```

### `GET /api/lessons/[roomToken]`
* **Доступ:** Участники урока (`teacher` или `student`, прикрепленный к уроку).
* **Назначение:** Получение метаданных урока перед входом в видеокомнату.

### `POST /api/lessons/[id]/complete`
* **Доступ:** `teacher`, `admin`.
* **Назначение:** Завершение урока, фиксация длительности, сохранение сохраненного снимка интерактивной доски и автоматическое списание 1 занятия с баланса ученика.
* **Тело запроса:**
```json
{
  "duration_minutes": 45,
  "whiteboard_snapshot_url": "https://.../snapshots/room-sh-zh.png",
  "teacher_summary": "Отлично отработали произношение звука 'Ш', рекомендована артикуляционная гимнастика."
}
```

## 3. WebRTC Signaling & Realtime Каналы
Прямой обмен медиапотоками 1-на-1 (видео, звук, демонстрация экрана) осуществляется напрямую через WebRTC PeerConnection внутри РФ (STUN: `stun.sipnet.ru`). Сигналинг и доска работают через Supabase Realtime:

* `lesson-room:[roomToken]` (Broadcast) — обмен SDP Offer, Answer и ICE-кандидатами.
* `whiteboard:[roomToken]` (Broadcast) — синхронизация штрихов рисования, геометрических фигур и очистки холста.
* `room-presence:[roomToken]` (Presence) — отслеживание готовности участников в комнате («В сети», «На связи»).

## 4. Образовательный Мессенджер

### `GET /api/chats`
* **Доступ:** `student`, `teacher`.
* **Назначение:** Список активных диалогов (преподаватель ↔ ученик/родитель) и системного чата уведомлений.

### `GET /api/chats/[id]/messages`
* **Доступ:** Участники диалога.
* **Назначение:** Пагинация истории сообщений, голосовых заметок и файлов.

### `POST /api/chats/[id]/messages`
* **Доступ:** Участники диалога.
* **Тело запроса:**
```json
{
  "text": "Здравствуйте! Прикрепила запись выполнения упражнения.",
  "file_url": "https://.../chat-attachments/voice-record-01.webm",
  "file_type": "audio_voice"
}
```

## 5. Домашние Задания

### `GET /api/homework`
* **Доступ:** Авторизованный пользователь (ученик видит свои ДЗ, учитель — выданные им).

### `POST /api/homework/create`
* **Доступ:** `teacher`.
* **Назначение:** Выдача домашнего задания ученику с дедлайном и прикрепленными материалами.

### `POST /api/homework/[id]/submit`
* **Доступ:** `student`.
* **Назначение:** Отправка выполненного задания (текст, фото тетради или аудиофайл).

### `POST /api/homework/[id]/review`
* **Доступ:** `teacher`.
* **Назначение:** Проверка ДЗ, выставление статуса (`reviewed`) и обратной связи.

## 6. Административная Панель и Баланс Уроков

### `GET /api/admin/users`
* **Доступ:** `admin`.
* **Назначение:** Список всех учеников и педагогов центра «АйДаУмничка», фильтр по балансу и активности.

### `POST /api/admin/balance/adjust`
* **Доступ:** `admin`.
* **Назначение:** Начисление (+4, +8, +16) или ручная корректировка баланса занятий с созданием записи аудита.
* **Тело запроса:**
```json
{
  "student_id": "a8f1b2c3-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
  "amount": 8,
  "description": "Оплата абонемента на 8 занятий (апрель)"
}
```

### `POST /api/admin/pair`
* **Доступ:** `admin`.
* **Назначение:** Закрепление ученика за преподавателем центра.
