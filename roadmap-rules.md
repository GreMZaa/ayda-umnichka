# 🗺️ Roadmap & Task Decomposition Rules: Платформа «АйДаУмничка»

## 1. Декомпозиция задач (Файл tasks.json)
* **Строгий JSON-формат:** Все задачи проекта ведутся в `tasks.json` для отслеживания статусов выполнения этапов разработки.
* **Категории задач:**
  * `infrastructure` — настройка Next.js, схемы Supabase PostgreSQL (DDL), RLS-политики, окружение Vercel.
  * `security` — валидация JWT-сессий, проверка ролей (`student`, `teacher`, `admin`), безопасный доступ к хранилищу.
  * `functional` — управление on-demand уроками, учет и списание баланса занятий, проверка и сдача домашних заданий.
  * `realtime` — WebRTC P2P сигналинг (SDP/ICE), синхронизация интерактивной доски (Whiteboard) через Supabase Broadcast.
  * `ui` — личный кабинет ученика, кабинет преподавателя, админ-панель центра, экран видеоурока и интерактивная доска.
  * `messenger` — чат диалогов, запись и воспроизведение голосовых сообщений, передача учебных файлов.
* **Пул задач:** Задачи формулируются атомарно с четкими критериями готовности (Definition of Ready / Done).

## 2. Критерии качества задачи (Definition of Ready)
* **Атомарность:** Каждая задача должна быть самодостаточной и завершаться валидным коммитом или рабочей функциональностью.
* **Изолированность:** Изменения в одном модуле (например, Whiteboard) не нарушают работу соседних (мессенджер, баланс).
* **Тестируемость:** Каждая задача содержит шаги ручной или автоматической проверки (проверка сборки, работа компонентов, отсутствие ошибок типов).

## 3. Критический путь разработки (Critical Path)
Порядок реализации платформы «АйДаУмничка»:
1. **Схема БД & Безопасность (Supabase):** таблицы пользователей, связок, уроков, чатов, сообщений, ДЗ и транзакций баланса с RLS.
2. **Клиентская архитектура (Next.js 15 / React 19):** настройка Tailwind CSS, системы дизайн-токенов «АйДаУмничка», базовых UI-компонентов shadcn.
3. **Личные кабинеты и ролевой доступ:** профиль ученика с виджетом баланса, кабинет педагога со списком учеников, панель администратора для начисления уроков.
4. **Комната урока и WebRTC P2P:** сигналинг через Supabase Broadcast, видеопотоки, аудиоконтролы, шаринг экрана.
5. **Интерактивная доска:** совместное рисование на холсте, инструменты, вставка обучающих картинок, экспорт снимка.
6. **Мессенджер и голосовые сообщения:** обмен текстом, аудиозапись с микрофона, сдача домашних заданий.
7. **Верификация и сборка:** компиляция TypeScript (`tsc --noEmit`) и успешный билд Next.js (`npm run build`).

## 4. Логирование прогресса (Файл progress.md)
* После закрытия каждого этапа результат фиксируется в `progress.md`.
* Запись содержит: цель этапа, созданные и измененные файлы, статус компиляции и результат проверки.
